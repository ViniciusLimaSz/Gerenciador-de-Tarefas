# Gerenciador de Tarefas

Projeto de console desenvolvido em Java para praticar os fundamentos da linguagem e conceitos iniciais de orientação a objetos.

## Funcionalidades

- Criar tarefa
- Listar tarefas
- Concluir tarefa
- Remover tarefa
- Definir prioridade
- Validação de entradas

## Conceitos praticados

- Classes e objetos
- Construtores
- Encapsulamento
- ArrayList
- Enum
- Métodos
- Loops
- Switch
- Exceptions
- Scanner

## Tecnologias

- Java
